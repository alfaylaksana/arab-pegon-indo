# Indo Arab Pegon

Keyboard Keyman untuk mengetik Arab, Pegon, dan Latin dalam satu keyboard — karya Muhammad Arif Hidayat.

## Fitur
- Tata letak huruf Arab standar (sesuai keyboard Arab Android pada umumnya)
- Baris khusus karakter Pegon (untuk Bahasa Jawa/Indonesia beraksara Arab)
- Layer Latin lengkap dengan Shift (sekali tekan = 1 huruf kapital, dua kali tekan = capslock)
- Auto-kapital otomatis di awal kalimat
- Layer angka, harakat, dan tanda baca

## Cara instal
1. Pastikan aplikasi **Keyman** sudah terpasang di HP (unduh dari Play Store / App Store kalau belum ada)
2. Unduh file `indo_arab_pegon.kmp` di repositori ini (klik file → tombol unduh/Download)
3. Buka file yang sudah diunduh — HP akan otomatis menawarkan untuk membukanya dengan aplikasi Keyman
4. Ikuti langkah pemasangan di Keyman, lalu aktifkan keyboard "Indo Arab Pegon" di pengaturan keyboard HP

## Catatan: kalau keyboard terasa lemot
Setelah dipakai cukup lama (biasanya sekitar 30 menit ke atas), keyboard ini bisa terasa sedikit melambat, dan kadang pindah antar-layer (misalnya dari Arab ke Latin) perlu ditekan lebih dari sekali. Ini bukan kerusakan pada file keyboard-nya, melainkan karakteristik aplikasi Keyman sendiri (mesin WebView-nya menumpuk beban selama dipakai terus-menerus dalam satu sesi).

**Cara mengatasi:** pindah sebentar ke keyboard lain (misalnya keyboard bawaan HP), lalu balik lagi ke Keyman. Ini akan me-reset keyboard dan mengembalikannya ke kondisi ringan seperti semula. Bukan solusi permanen, tapi cukup praktis dilakukan sesekali saat mengetik dalam waktu lama.
